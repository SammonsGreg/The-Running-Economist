The Running Economist
Smarter miles.
A personalized execution, observation, and reflection system for running.
The Running Economist is a personal running project designed around a specific runner's training history, goals, performance profile, pace/heart-rate/RPE relationships, training principles, and 24-week training schedule.
The application is designed to answer four questions each day:
What am I doing today?
How should I execute it?
What guardrails apply?
What happened when I did it?
Philosophy
The application observes, records, compares, and explains. It does not autonomously alter training.
Privacy
The application runs entirely in the browser. Training logs are stored locally in browser storage and are not transmitted to a server.
Technology
Single-file HTML application
Vanilla JavaScript
CSS
No build tools
No framework
No external database
Responsive design
Local browser storage
Purpose
This is a personal project, not a commercial coaching platform or medical application.
